# BZT Health Care Clinic 弼正堂 — 网站说明

## 项目简介

BZT Health Care Clinic（弼正堂）的官方网站，纯静态网页，托管在 GitHub Pages（免费），网址：https://bzt-health-care-clinic.github.io/

技术栈：HTML + CSS + 原生 JavaScript，无框架、无后端，打开快、维护简单。

## 页面结构

| 页面 | 说明 |
|------|------|
| `index.html` | 首页：诊所介绍、服务概览、预约入口 |
| `services.html` | 服务总览（针灸 / 拔罐 / 艾灸 / 中药） |
| `service-acupuncture.html` 等 4 页 | 每个服务的独立介绍页 |
| `price.html` | 价格表（拔罐 30 分钟、中药处方：C$40 / US$30） |
| `business-hours.html` | 营业时间（工作日 2:00–5:00 pm，周六 10:00 am–5:00 pm，仅限预约） |
| `health-tips.html` | 健康小贴士 |
| `contact.html` | 联系方式＋在线预约表单 |

## 现有功能

- **中英双语**：关键信息（地址、营业时间、预约提示）中英文对照。
- **在线预约表单**：姓/名分开必填、电话、邮箱、预约项目、日期（YYYY-MM-DD 数字输入）、保险公司（选填）、留言；通过 FormSubmit 发送到 shirley.zqx@gmail.com，带防机器人（honeypot）和自定义邮件主题。
- **"预约请指定针灸师 Shirley Xu"**：首页、营业时间、联系页三处保留中英文提示。
- **手机端适配**：汉堡菜单、响应式布局；FAQ 手风琴展开。
- **微信二维码**：联系页放了微信二维码图片，方便华人客户加微信。

## 部署

仓库：`bzt-health-care-clinic/bzt-health-care-clinic.github.io`，`main` 分支即网站根目录，push 后约 1 分钟自动上线。注意：图片等二进制文件必须走 git 命令推送，不能用网页端的文件上传接口（会损坏）。

## 可延伸的方向

以下都是现在没做、以后可以加的，按投入从小到大排：

1. **预约自动回复**：客户提交表单后自动收到一封确认邮件（"已收到您的预约请求"），现在是手动回。FormSubmit 支持 `_autoresponse`，开一下就行。
2. **可预约时间表**：把 Google Calendar 的空闲时间嵌进网页，客户直接看到哪天有空位，不用来回问。现在还是客户填日期、你人工确认。
3. **已占时间自动约不上**：和上一条配合，日历上有约的时间段表单里选不了，避免撞期。
4. **在线评价展示**：把 Google 好评截几条放首页，新客户信任感强很多。
5. **健康文章定期更新**：`health-tips.html` 现在是静态的，可以每月加一篇（比如换季养生、针灸常识），对 Google 搜索排名有帮助。
6. **SEO 优化**：现在标题和描述是基础版，可以针对 "Coquitlam acupuncturist / 高贵林 针灸" 这类关键词再打磨，让附近的人更容易搜到。
7. **在线支付定金**：如果以后想收预约押金防爽约，可以接 Stripe 付款链接。
8. **多语言切换按钮**：现在是中英混排，以后可以做一键切换中文版/英文版。

> 原则：网站和 BrokerDesk 是两个完全独立的项目，互不影响。改网站只动这个仓库，不碰其他任何东西。
